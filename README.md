# Elgato Key Light Camera Control для macOS

Автоматическое управление Elgato Key Light Neo в зависимости от состояния камеры на macOS.

## Описание

Это приложение работает в фоновом режиме и автоматически:
- ✅ **Включает** Elgato Key Light Neo при активации камеры
- ✅ **Выключает** Elgato Key Light Neo при деактивации камеры
- ✅ Работает как menu bar приложение (в строке меню)
- ✅ Поддерживает ручное тестирование включения/выключения света

## Требования

- macOS 13.0 (Ventura) или новее
- Elgato Key Light Neo (или обычный Key Light)
- Swift 5.9+ и Xcode 15+ (для сборки)
- Elgato Key Light должен быть подключен к той же локальной сети

## Как найти IP адрес вашего Elgato Key Light

1. Откройте официальное приложение Elgato Control Center
2. Зайдите в настройки устройства
3. IP адрес будет показан в информации об устройстве
4. Альтернативно: используйте приложение для сканирования сети (например, Fing)

Доступно **два варианта** использования:

### 🐍 Вариант 1: Python скрипт (БЫСТРЫЙ СТАРТ)

Самый простой способ начать использовать:


**Преимущества Python версии:**
- ✅ Не требует компиляции
- ✅ Работает сразу "из коробки"

- ✅ Простой запуск через терминал

**Ограничения:**
- ❌ Нет GUI интерфейса
- ❌ Работает только когда терминал открыт
- ❌ Нужно запускать вручную

## Первоначальная настройка

1. При первом запуске приложение попросит ввести IP адрес вашего Elgato Key Light
2. Введите IP адрес (например: `192.168.1.100`)
3. Приложение появится в строке меню (иконка лампочки)
4. Система может запросить разрешение на доступ к камере - **обязательно разрешите**

## Использование

### Автоматический режим

После настройки приложение работает автоматически:
- Запустите любое приложение, использующее камеру (Zoom, FaceTime, Photo Booth и т.д.)
- Key Light автоматически включится
- Закройте приложение или выключите камеру
- Key Light автоматически выключится

### Меню приложения

Кликните на иконку в строке меню для доступа к:
- **Status** - текущее состояние (камера активна/неактивна)
- **Configure Key Light IP** - изменить IP адрес света
- **Test Light On** - вручную включить свет
- **Test Light Off** - вручную выключить свет
- **Quit** - выход из приложения

## Автозапуск при входе в систему

Чтобы приложение запускалось автоматически:

1. Откройте **Системные настройки** → **Основные** → **Объекты входа**
2. Нажмите "+" и добавьте ElgatoCameraControl
3. Приложение будет запускаться при каждом входе в систему

## Технические детали

### Как работает мониторинг камеры

Приложение использует два метода для определения активности камеры:

1. **AVFoundation API** - проверяет статус подключенных камер
2. **lsof** - проверяет системные процессы, использующие камеру

Это обеспечивает надежное определение даже когда камера используется в разных приложениях.

### API Elgato Key Light

Приложение использует официальный HTTP API Elgato:
- Порт: `9123`
- Endpoint: `/elgato/lights`
- Метод: `PUT` для управления светом

### Интервал проверки

Приложение проверяет статус камеры каждые **2 секунды**. Это обеспечивает быстрый отклик при минимальной нагрузке на систему.

## Устранение проблем

### Свет не включается/выключается

1. Проверьте, что Key Light включен и подключен к сети
2. Проверьте правильность IP адреса в настройках
3. Убедитесь, что Mac и Key Light в одной сети
4. Попробуйте ручные тесты "Test Light On/Off" из меню

### Приложение не видит камеру

1. Проверьте разрешения: **Системные настройки** → **Конфиденциальность и безопасность** → **Камера**
2. Убедитесь, что ElgatoCameraControl имеет доступ к камере
3. Перезапустите приложение

### Приложение не отображается в строке меню

1. Проверьте, что процесс запущен (Activity Monitor)
2. Попробуйте перезапустить приложение
3. Проверьте консоль на наличие ошибок
